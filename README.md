# FF Likes — موقع تجريبي لتبادل اللايكات

واجهة عربية RTL بتصميم داكن وأحمر، HTML/CSS/JavaScript فقط.

## تشغيل الموقع
1. فكّ ضغط الملف `ff_likes_exchange.zip`.
2. افتح مجلد `ff_likes_exchange`.
3. افتح `index.html` في المتصفح.

ما يلزمش تثبيت برامج أو سيرفر لتجربة الواجهة.

## شنوّة يخدم حالياً؟
- واجهة متجاوبة مع الهاتف والكمبيوتر.
- نموذج لإنشاء طلب تبادل تجريبي.
- حفظ الطلبات محلياً في `localStorage` على نفس المتصفح.
- عرض الطلبات ومسحها.

## حدود النسخة
- الطلبات ما تتبعثش للإنترنت وما يشوفها حتى لاعب آخر.
- ما فماش تسجيل دخول ولا قاعدة بيانات ولا رفع لايكات داخل اللعبة.
- التبادل الحقيقي يتطلب خدمة خلفية، قاعدة بيانات، حماية من الإساءة، وآلية تفاعل مسموح بها من Garena. لا تطلب أو تخزّن كلمات مرور اللاعبين.
- المشروع غير تابع لـ Garena أو Free Fire.

## قبل النشر
استبدل التخزين المحلي بخادم وقاعدة بيانات، أضف مصادقة آمنة وإجراءات منع السبام، وسياسة خصوصية وشروط استخدام. لا تدّعي أن الطلب اكتمل داخل اللعبة ما لم يتم التحقق منه فعلياً.
